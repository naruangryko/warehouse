## PC에서 실행해야 할 회귀 테스트

1. `gradle build`: 컴파일, 번역/리소스 처리, coreTest, remapJar 확인.
2. `gradle runClient`: 새 테스트 월드 생성, 창작 아이템 탭과 세 검 표시 확인.
3. 서바이벌에서 `/rpg quest accept`, 고블린 5킬, 레벨/XP 상승 확인.
4. `/rpg quest claim` 두 번 실행: 보상은 한 번만.
5. 힘·체력·민첩 배분 전후 실제 속성 확인, 보유 포인트보다 많은 배분 거부.
6. 대검 레벨 미달 공격/우클릭 거부, 충족 후 쿨다운과 내구도 감소.
7. 벽 뒤 몬스터, 반경 밖 몬스터, 다른 플레이어, 가축에 대검 범위 피해가 없는지 확인.
8. 사망·재접속·네더 이동·서버 재시작 후 진행 값과 속성 중복 여부 확인.
9. 서로 다른 플레이어 2명이 각자 의뢰를 진행해 킬/보상이 섞이지 않는지 확인.
10. 가득 찬 인벤토리에서 보상 잔여물이 드롭되며 복제되지 않는지 확인.
11. 평원/숲/타이가의 밤과 밝은 장소, peaceful, 스폰 가중치 0 비교.
12. 한국어/영어 전환, 액션바 끄기, 망가진 설정 JSON의 기본값 처리를 확인.

다음 개발 순서: 전체 빌드의 컴파일 오류부터 수정 → 위 게임 테스트 → 3단계 세력 시스템.
