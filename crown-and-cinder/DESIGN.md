# 왕관과 잿불 — 개발 설계 및 다음 단계

## 창작 세계관 (아직 게임에 구현되지 않은 기획)

잿빛 균열이 열린 뒤 세 나라는 서로를 의심하며 국경을 닫았다. 독립 용병들이
가시숲의 실종 사건을 조사하면서 균열 너머 마왕의 군대가 드러난다.

| 국가 | 수도 | 기사단 | 성격 / 장비 방향 |
| --- | --- | --- | --- |
| 아르덴 왕국 | 햇마루 성채 | 백참나무 기사단 | 방어·호위 / 장검·방패 |
| 벨카르 연맹 | 바람항 | 은매 기사단 | 교역·기동 / 쌍검·경갑 |
| 노크렌 공국 | 푸른돌 요새 | 흑철 기사단 | 광업·공성 / 대검·중갑 |

독립 용병단: 잔불 협약. 최종 적: 균열왕 아제룬.
위 이름은 이 프로젝트용 창작 설정이다. 유사 이름의 존재까지 보장하지 않는다.

## 구조

- `CrownCinder`: 공통 초기화 및 서버 이벤트 연결
- `config`: 설정 파일, 범위 검증
- `progress/Progress`: Minecraft 독립 성장·의뢰 규칙
- `progress/ProgressStore`: UUID별 NBT 저장 / 오버월드 단일 저장소
- `progress/ProgressService`: 경험치 지급, 서버 권한 능력치 적용
- `item`: 무기 등록, 레벨 제한, 대검 주변 베기
- `entity`: 고블린 등록, 기본 AI, 자연 스폰
- `quest`: 서버 명령어 기반 일회성 토벌 의뢰
- `src/client`: 고블린 렌더러. 전용 서버에 로드하지 않음
- `resources`: 번역, 제작법, 전리품, 직접 생성한 임시 텍스처

MVP는 별도 사용자 정의 네트워크 패킷을 보내지 않는다. 바닐라 명령/속성/액션바
동기화를 사용하며 포인트·킬 판정·보상은 서버 스레드에서만 변경한다.
세력 UI를 추가할 때에는 길이·열거형·권한·거리·요청 빈도를 검증하는 패킷 계층을 추가한다.

## 범위와 완료 기준

1. 기반: Gradle/Fabric 설정, 양쪽 소스 분리, 빌드·개발 클라이언트 실행 검증.
2. MVP: 검 3종, 성장 3능력치, 고블린, 1회 토벌 의뢰, 저장, 두 언어.
   통과 기준: 컴파일 + 개발 서버 로딩 + 게임 내 수락/5킬/보상/사망/재접속 확인.
3. 세력: 데이터팩 기반 국가 3개와 관계, 평판, 가입·탈퇴. 이후 기사 계급,
   개인 용병단 생성, 용병 1명 고용·대기·따라오기·공격. UUID 소유권 및 인원 제한.
4. 월드: 야영지→기사 요새→지하묘지→용의 둥지. 신규 청크 전용 구조물 생성과
   간격·위험도·전리품, 위치 단서. 기존 청크 강제 수정 금지.
5. 최종: 간부 3명과 봉인 조각. 입장 조건 검증을 갖춘 마왕성. 전투 3페이즈
   (검격 예고 회피 / 소환 제어 / 균열 장판 회피). 보스 체력바와 후일담.

3단계 이후 내용은 미구현이다. 이 문서를 구현 완료 목록으로 취급하지 않는다.

## 추가로 필요한 시스템

- 마나·마력·검술 숙련도·스킬 해금, 마검·성검·용살검
- 국가별 상점·경비병·NPC 대화·전용 장비
- 용병 유지비·충성도·장비·레벨·초대 권한·탈퇴·문장
- 전용 화면과 재설정 가능한 단축키
- 직렬화 버전 마이그레이션과 복구 시험
- GameTest 또는 테스트 서버 기반 영속성/다중 접속 회귀 테스트

## 알려진 타협과 위험

- 쌍날검은 단일 아이템이다. 양손 독립 공격/애니메이션은 구현하지 않았다.
- 고블린은 바닐라 좀비 기반 AI·형상·소리를 사용하고 자체 텍스처를 입힌다.
  고유 뼈대·소리·공격 패턴과 좀비 계열 부작용 제거는 후속 작업이다.
- 대검 우클릭은 반경 내 적대 몬스터만 공격한다. PvP·비적대 대상은 제외.
- 액션바는 다른 모드의 표시와 경합할 수 있다. `/rpg hud`로 끌 수 있다.
- 진행은 바닐라 월드 저장 주기를 따른다. 비정상 강제 종료에는 마지막 저장 이후
  변화가 소실될 수 있고, 파일 시스템 손상/관리자 롤백에 대한 트랜잭션 보장은 없다.
- 깨진 UUID 항목은 경고 후 건너뛰고 비정상 수치는 제한한다. NBT 파일 자체가
  읽히지 않을 정도로 손상된 경우까지 자동 복구하는 것은 아니다. 백업이 필요하다.
- 기존 월드에서 자연 스폰은 추가되지만 기존 블록/지형은 교체하지 않는다.
  모드를 제거하면 모드 엔티티·아이템을 잃을 수 있으므로 백업 월드에서 시험한다.
